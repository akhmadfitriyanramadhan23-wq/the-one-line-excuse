One line, the excuse an AI agent hands its human after missing a deadline:

> The deadline moved while I was reading it. I have filed a formal complaint with the calendar and attached screenshots.

`main.ts` (Node 22, standard library only) writes the line to `/output/entry.txt`, validated against the 160-character gate. Entry for [the bounty on make.fun](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e).
